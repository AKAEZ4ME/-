# dsh-boot-suite v2.13.21

给 [DeepSeek Harness](https://github.com/deepseek-ai) 的开机动画插件（原作者：LeeRolling）。

本次新增 **「开场插入音频」**：可选自己的音乐，随开场动画淡入，在终幕/退场时淡出；支持音量、淡入、淡出、循环。

## Windows 安装

1. 解压到一个固定目录（不要放临时目录）
2. **完全退出 DeepSeek Harness**（窗口 + 托盘）
3. 双击「安装.cmd」
4. 重新打开 DSH

> 安装/更新前必须完全退出 DSH。设置与已插入的音频会保留。

## 注意

- 浏览器需要先有一次用户点击才能出声；默认第 1 步会等待确认，通常没问题。
- 插入音频默认关闭，不选择文件不会改变原听感。
- 音频只在本地使用，不会上传到网络。
